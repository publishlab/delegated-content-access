# CPython 3.14, linux, glibc 2.34 or newer. One --hash line is one wheel.
#
# cryptography is the lane's only real dependency. cffi and pycparser are here
# because --no-deps alone gives a cryptography that will not import at all:
# `from cryptography.hazmat.primitives import hashes` raises
# ModuleNotFoundError: No module named '_cffi_backend' from the Rust bindings.
#
# Why this file is per abi tag, where the other lanes pin one tarball per arch:
#   cryptography  ships cp311-abi3 wheels, so any CPython 3.11+ takes the same
#                 file, but it publishes manylinux_2_17 / _2_28 / _2_34 builds
#                 of that one version and pip picks by the host's glibc. The
#                 hashes below are the _2_34 builds; install-toolchain
#                 refuses an older host by name rather than letting pip ask for
#                 a file this list does not carry.
#   cffi          ships no abi3 wheel. The pin covers cp314-cp314 only, and
#                 that ties this file to one interpreter minor version.
#   pycparser     pure Python, the same py3-none-any wheel everywhere, so both
#                 architectures take the one hash.
#
# Why the arch is not in the name, where the abi tag and the libc are: pip's
# hash-checking mode takes several --hash lines per requirement and installs a
# file matching any one of them, which is how one list covers several binary
# distributions of a release. pip then picks which wheel to ask for by the host
# tags, so the arch-wrong wheel is never requested and its hash is never
# reached. Each block below carries the x86_64 hash first and the aarch64 hash
# second.
#
# x86_64 is the arch this lane has actually run on. No arm machine was available
# when the lane was written, so every aarch64 hash here was read off the API and
# not executed, and those two lines stay unproven until the first aarch64 run.
# A wrong hash there fails loudly at the install and lets no wheel through.
#
# Read off the PyPI JSON API on 2026-08-27,
# .urls[] | select(.filename == ...) | .digests.sha256:
#   https://pypi.org/pypi/cryptography/50.0.1/json
#   https://pypi.org/pypi/cffi/2.1.1/json
#   https://pypi.org/pypi/pycparser/3.0/json

# cryptography-50.0.1-cp311-abi3-manylinux_2_34_x86_64.whl   (run here)
# cryptography-50.0.1-cp311-abi3-manylinux_2_34_aarch64.whl  (never executed)
cryptography==50.0.1 \
    --hash=sha256:51afcfceb15597cf2635068e4ac9a56b2abde622edde17f37d85fd7b5306497a \
    --hash=sha256:e2ca8fd1b6b4b82a1c4cb02841d0837e3c12336c2e24b520ab8ab3b969733d8f

# cffi-2.1.1-cp314-cp314-manylinux2014_x86_64.manylinux_2_17_x86_64.whl   (run here)
# cffi-2.1.1-cp314-cp314-manylinux2014_aarch64.manylinux_2_17_aarch64.whl (never executed)
